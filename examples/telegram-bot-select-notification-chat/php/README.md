# Выбор группы или канала

Нужны 64-битный PHP 8.3+ с PDO SQLite и cURL, HTTPS и отдельный тестовый бот. Создайте свою группу либо канал и назначьте бота администратором. Для канала выдайте право публикации.

1. Укажите `public/` корнем сайта. Задайте `BOT_DB_PATH` с новым файлом вне веб-корня, `BOT_TOKEN` и общий `WEBHOOK_SECRET` в окружении веб-процесса и CLI. Для CLI задайте полный `WEBHOOK_URL` и числовой `BOT_ID` из getMe.
2. Выполните `php init.php` и `php setup-webhook.php`. Откройте личный чат и напишите /group или /channel. Выполните `php worker.php`, выберите чат и запустите worker ещё раз.
3. В выбранном чате ожидайте пробное сообщение. В личном чате появится «Чат подключён». В SQLite запрос `SELECT user_id,chat_id,kind,active FROM integrations;` покажет active=1. Если пробный ответ не подтверждён, новое подключение не активируется.
4. Для отдельного тестового события выполните `php notify.php 123456789 demo-event-001` со своим ID. Повтор с тем же ключом не создаёт повторного запроса. После /disconnect и обработки worker новое уведомление не отправляется.

`bot.php` создаёт запрос, проверяет чат, права и отправляет пробное сообщение. `public/webhook.php` записывает update в inbox, `worker.php` читает его, а `runtime.php` хранит исходы внешних действий. `notify.php` повторно проверяет права перед своим вызовом. Учебная политика принимает создателя чата. Для администратора настройте отдельные требования к правам владельца приложения и бота.
