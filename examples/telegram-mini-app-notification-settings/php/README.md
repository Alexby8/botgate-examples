# Экран настроек и очередь Telegram

Нужны HTTPS, тестовый бот и 64-битный PHP 8.3+ с cURL и PDO SQLite. Используйте одну установку на бота.

1. Назначьте корнем сайта `public/` с обработкой PHP. Создайте закрытый каталог для базы. Задайте BOT_DB_PATH с абсолютным путём к SQLite и BOT_TOKEN для PHP веб-сервера и CLI. Запустите `php init.php` на новом файле базы.
2. Добавьте адрес `/settings.html` в меню тестового бота. Откройте его в личном чате, включите статусы заказов и сохраните настройки. Кнопкой «Разрешить боту писать» можно запросить разрешение в Telegram.
3. Для входящих событий задайте WEBHOOK_URL с полным HTTPS-адресом `/webhook.php` и случайный WEBHOOK_SECRET в CLI и у PHP веб-сервера. `php setup-webhook.php` зарегистрирует webhook тестового бота.
4. Подставьте ID своего тестового аккаунта и уникальный ключ. Команда worker попытается отправить сообщение этому пользователю, если категория включена и время разрешено.

```bash
php enqueue-demo.php 123456789 test-order-01
php worker.php
```

С тишиной, включённой на текущее время, ожидайте pending с новым due_at. При отключённой категории ожидайте skipped. При успешной отправке ожидайте sent и message_id. Запрос для просмотра состояния: `SELECT event_key,state,due_at,message_id FROM notifications ORDER BY id;`.

| Файл | Назначение |
| --- | --- |
| `public/settings.html`, `public/preferences-api.php` | Экран, загрузка и сохранение. |
| `auth.php`, `public/webhook.php` | Проверка пользователя и обработка нового разрешения Telegram. |
| `preferences.php`, `schema.sql` | Таблицы, местное время, проверка категории и извлечение задачи. |
| `worker.php`, `telegram.php` | Попытка отправки и результат Bot API. |

При /start или write_access_allowed снимается известная блокировка для новых событий. Старые skipped и blocked остаются закрытыми.
