# Отчёт о продажах и заявках

Нужен 64-битный PHP 8.3+ с PDO SQLite, для отправки понадобится cURL. Запускайте из этой папки. Задайте APP_DB с абсолютным путём к новому закрытому SQLite-файлу, REPORT_TIMEZONE=Europe/Moscow и REPORT_CHAT_ID тестового чата. Для worker задайте BOT_TOKEN тестового бота. CLI читает параметры из окружения.

```bash
php init.php
php demo.php 2026-11-18
php report.php 2026-11-18
```

В SQLite выполните `SELECT id,state,text FROM reports;`. Ожидается один отчёт с 1 500 ₽ поступлений, 200 ₽ возвратов, 1 300 ₽ чистых поступлений и двумя заявками. Повтор команды вернёт ID прежнего снимка. С неполными курсорами на новой дате отчёт не появится.

Для отправки этого отчёта в настроенный тестовый чат выполните `php worker.php`. В состоянии sent должен быть message_id. При unknown или остановке в sending сверьте чат. `php review.php ID confirmed-sent` фиксирует найденное сообщение, а `php review.php ID retry` разрешает повтор после ручной проверки.

| Файл | Назначение |
| --- | --- |
| `demo.php`, `schema.sql`, `init.php` | Два учебных дня, курсоры источников и создание таблиц. |
| `reporting.php`, `report.php` | Границы периода, проверка полноты, итоги и сохранение текста. |
| `transport.php`, `worker.php`, `review.php` | Отправка, исход попытки и ручная сверка. |

Планировщик может запускать report.php утром и worker.php каждую минуту. Передайте обоим те же переменные окружения. У внешнего импорта сохраняйте данные и границу полноты одной операцией.
