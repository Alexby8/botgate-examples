# Каталог Telegram-бота через Google Таблицы

[Статья с пошаговым разбором](https://bot-gate.ru/guides/telegram-bot-google-sheets-catalog).

Менеджер меняет товары, цены и доступность в таблице. Приложение проверяет весь
набор и сохраняет рабочую копию. Бот отвечает из этой копии, которая сохраняется
при ошибке чтения или некорректных данных.

## Реализации

- **[PHP](php/README.md)** — Google Auth, проверка каталога, SQLite и команды бота.

Начните с формата таблицы и `catalog.php`; готовый webhook и очередь уведомлений
нужны при запуске отдельного тестового бота. В примере нет оплаты и резервирования склада.
Папки других языков можно добавлять рядом с `php`.
