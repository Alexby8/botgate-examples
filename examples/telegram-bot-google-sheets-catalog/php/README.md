# Каталог из Google Таблиц — PHP

[Статья](https://bot-gate.ru/guides/telegram-bot-google-sheets-catalog) · [Обзор и языки](../README.md).

Пример читает таблицу, проверяет товары целиком и сохраняет рабочий снимок в SQLite.
Бот показывает каталог и карточку товара. Ошибка Google или данных не удаляет
последнюю рабочую версию. В примере нет заказа, оплаты или резервирования склада.

Нужны PHP 8.3+ (64-bit), pdo_sqlite, mbstring, curl, openssl и Composer 2.
Все команды ниже выполняются из `examples/telegram-bot-google-sheets-catalog/php`.

## 1. Подготовьте таблицу

Создайте Google Таблицу с вкладкой `Catalog`. Скопируйте TSV-шаблон в A1
или импортируйте его с разделителем «табуляция». Шапка и порядок колонок:

```text
id    title    price_minor    active    stock
```

- `id` постоянный, не номер строки. Не меняйте его при сортировке и переименовании.
- `price_minor` — целое число копеек: 149000 означает 1490 ₽.
- `active` — обычный флажок с логическим значением; не задавайте «да/нет» вручную.
- `stock` — целый остаток, ноль допустим; пустая ячейка считается ошибкой.
- Для отключения снимите `active`; удаление ранее загруженного ID отклоняется.
- До 1000 товаров, без размещения строк за большим пустым разрывом вне A1:E1002.

## 2. Подключите Google

В Google Cloud включите Sheets API, создайте service account и его JSON-ключ,
если это разрешено политикой организации. Сохраните свой ключ как
`google-reader.json` рядом с этим README, вне `public`.
Добавьте `client_email` из ключа в доступ к таблице с ролью читателя.
ID таблицы — часть URL между `/d/` и `/edit`.

Скопируйте `config.example.php` в `config.local.php` и заполните SHEET_ID.
Остальные Google-пути уже заданы относительно текущей папки. В PowerShell
можно использовать `Copy-Item`, в Bash — `cp`; обычный файловый менеджер тоже подходит.

```bash
composer install --no-dev
php init.php
php sync.php
php inspect.php /item mug-450
```

`init.php` выполняется один раз для новой базы. Ожидаются `Catalog checked and installed`
и «Термокружка 450 мл — 1490,00 ₽». `inspect.php` читает базу, Google и Telegram не вызывает.
`php inspect.php /catalog 2` показывает вторую страницу (или последнюю существующую).
Окружение процесса имеет приоритет над одноимёнными параметрами config.local.php.

При ошибке строки исправьте её и повторите sync. При ошибке доступа проверьте ключ,
включённый API, SHEET_ID, название вкладки и доступ client_email. Сбой не должен
заменяться пустым каталогом. Успех очищает ошибку в sync_state и обновляет checked_at.

## 3. Подключите отдельного тестового бота

Создайте бота в BotFather. В config.local.php задайте BOT_TOKEN, WEBHOOK_URL
и случайный WEBHOOK_SECRET (32–256 символов: буквы, цифры, `_`, `-`).
Для генерации секрета: `php -r "echo bin2hex(random_bytes(32)), PHP_EOL;"`.

Разместите пример на HTTPS с корнем сайта `php/public`, например
`/srv/catalog-bot/public`, если языковая папка скопирована в `/srv/catalog-bot`.
Конфигурация, ключ, `vendor` и `var/app.sqlite` должны быть выше публичного корня.
Процесс PHP и CLI должны читать одну конфигурацию и иметь доступ на запись в `var`.

В WEBHOOK_URL укажите `https://ваш-домен/webhook.php`. Следующая команда меняет
адрес webhook этого бота; не запускайте её для бота с другой работающей интеграцией:

```bash
php setup-webhook.php
```

После `sent` откройте чат бота, отправьте `/catalog`, затем выполните
`php worker.php`. Ожидается список из таблицы. `/item mug-450` покажет карточку.
Получение команды сохраняет ответ в outbox; доставка выполняется worker отдельно.

## 4. Проверьте изменения менеджера

1. Измените 149000 на 159000, выполните sync и запросите новую карточку: 1590,00 ₽.
2. Снимите active у mug-450 и синхронизируйте: товар скрыт.
3. Верните active и введите отрицательную цену. Sync завершится ошибкой,
   предыдущая принятая версия останется — товар всё ещё скрыт.
4. Исправьте цену, повторите sync: товар вернётся. Старые сообщения в чате сами не обновляются.

Повтор ID, удалённая строка, пустой остаток и неполная шапка отклоняются целиком.
Если все товары отключены корректно, бот сообщает, что доступных товаров нет.
Если первого успешного импорта не было, он сообщает, что каталог пока недоступен.
Через 15 минут без успешной проверки появляется просьба уточнить цену и наличие.
Порог 15 минут и расписание ниже — правила этого примера, а не ограничения Google.

## Расписание и доставка

Пример для Linux; адаптируйте путь к своему приложению:

```cron
*/5 * * * * cd /srv/catalog-bot && php sync.php
* * * * * cd /srv/catalog-bot && php worker.php
```

Следите за stderr планировщика. Локальная файловая блокировка не допускает
одновременных sync; SQLite и эта блокировка рассчитаны на один сервер.
Планировщик должен иметь доступ к той же конфигурации и базе, что и веб-процесс.

Ответы `unknown` и оставшиеся после аварии `sending` не повторяются автоматически:
сначала проверьте конкретное сообщение в чате. Подтверждённый лимит Telegram
обрабатывается с задержкой и ограниченным количеством попыток. Запись в очереди
не доказывает доставку и не гарантирует отсутствие дубля при потерянном ответе сети.

## Проверка без внешних сервисов

`php demo.php` использует fixtures/catalog.json и SQLite в памяти: показывает карточку,
отклоняет отрицательную цену и проверяет сохранность снимка. Ожидается `DEMO OK`.
Эта команда не требует Composer, ключей и токена. Реальный доступ Google и доставка
Telegram проверяются отдельным проходом по шагам выше.
