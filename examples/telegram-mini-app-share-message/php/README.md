# Публичная карточка синей кружки

Нужны PHP 8.3+ с cURL, отдельный тестовый бот, HTTPS и клиент Telegram с поддержкой shareMessage (8.0+). База не требуется.

1. Укажите корнем сайта `public/` и настройте PHP. Передайте веб-процессу `BOT_TOKEN` и `PUBLIC_SHOP_URL` с действующим публичным HTTPS-адресом магазина. Учебные данные в `card.php` описывают кружку и блокнот, замените их своим публичным каталогом.
2. Укажите полный адрес `/share.html` в меню тестового бота. [Настройка меню](https://bot-gate.ru/guides/telegram-mini-app-html-php-form#launch)
3. Откройте Mini App. В предпросмотре должны быть «Синяя кружка, 350 мл», цена 650 ₽ и URL. Нажмите «Поделиться» и выберите тестовый чат. Сверьте сообщение и кнопку «Открыть товар».
4. Прервите следующую отправку закрытием окна. Интерфейс покажет отсутствие подтверждения. Истёкшую карточку можно подготовить заново. Клиент без shareMessage предлагает скопировать публичную ссылку.

`public/share.html` показывает карточку и вызывает shareMessage. `public/prepare.php` проверяет подпись через `auth.php`, собирает карточку через `card.php` и вызывает Bot API через `telegram.php`. Неизвестный товар даёт 404, просроченные данные Telegram — 401, временный лимит — 429 с Retry-After.
