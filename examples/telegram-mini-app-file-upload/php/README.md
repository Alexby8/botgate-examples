# Заявка на ремонт с вложениями

Нужны тестовый бот, HTTPS и 64-битный PHP 8.3+ с PDO SQLite, mbstring и fileinfo. Создайте отдельную установку для каждого бота. Команды выполняйте из этой папки.

1. Настройте сайт с обработкой PHP и корнем `public/`. Создайте закрытые каталоги для базы и вложений вне этого корня. Пользователю PHP нужны права записи. На Linux назначьте каталогам режим 0700 и запустите установку от того же системного пользователя, что и веб-процесс.
2. Передайте окружению PHP переменные APP_DB (полный путь к файлу SQLite), UPLOAD_DIR (полный путь к существующему каталогу) и BOT_TOKEN. Для CLI достаточно APP_DB. Запустите `php init.php` один раз на пустом файле базы.
3. Установите PHP-параметры file_uploads=On, upload_max_filesize=6M, post_max_size=20M, max_file_uploads=10, max_execution_time=90 и display_errors=Off. Согласуйте лимит тела на веб-сервере, например 20 МиБ. Приложение принимает JPEG, PNG и PDF по 5 МиБ, максимум три файла.
4. Укажите в меню тестового бота HTTPS-адрес `/form.html`. Пример настройки через setChatMenuButton есть в [статье о первой форме](https://bot-gate.ru/guides/telegram-mini-app-html-php-form#launch). Откройте форму из личного чата.
5. Введите «Разбит экран ноутбука» и приложите PNG и PDF. Форма покажет предпросмотр PNG и размер двух файлов. Ожидайте номер заявки и две кнопки скачивания. В SQLite запрос `SELECT id, user_id FROM requests;` покажет заявку, а `SELECT request_id, id, mime, bytes FROM attachments;` — два вложения.

| Файл | Назначение |
| --- | --- |
| `public/form.html` | Выбор, предпросмотр, multipart, проверка результата и скачивание. |
| `public/api.php`, `auth.php` | Приём запроса, проверка initData, получение результата по ключу. |
| `uploads.php`, `schema.sql` | Проверка MIME и размера, запись владельца и метаданных, перенос файлов. |
| `public/download.php` | Проверка владельца и отправка файла. |
| `common.php`, `values.php`, `init.php` | Соединение с SQLite, типизация значений и создание таблиц. |

Проверьте файл больше 5 МиБ и текстовый файл под именем photo.png. Первый должен получить сообщение о размере, второй — о допустимых форматах. При повторе того же multipart с прежним ключом вернётся тот же номер. При изменении содержимого вернётся 409. Владелец скачивает файл, другой подписанный пользователь получает 404 даже при известном ID.
