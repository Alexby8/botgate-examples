# Публикация новостей из RSS

Нужен 64-битный PHP 8.3+ с DOM, mbstring, PDO SQLite и cURL. Команды выполняйте из этой папки.

```bash
php demo.php
```

Демонстрация читает три XML из fixtures и использует SQLite в памяти. Архив оставляет 0 строк в очереди, новая запись создаёт 1 строку, правка при прежнем guid оставляет ту же строку. В конце печатается текст для sendMessage. Демонстрация работает без обращения к сети.

## Тестовый канал

1. Добавьте бота администратором с правом публиковать сообщения. Для теста подойдёт отдельный канал без подписчиков. Задайте CHANNEL_ID с @именем публичного канала или числовым ID.
2. Задайте окружение PHP. APP_DB — абсолютный путь к SQLite в закрытом каталоге с правом записи, FEED_URL — управляемая вами HTTPS-лента RSS 2.0, BOT_TOKEN — токен бота. KEYWORD — необязательная подстрока заголовка. Одна установка обслуживает один канал и один источник.
3. Запустите `php init.php` один раз, затем `php poll.php`. Первая успешная загрузка фиксирует архив. Добавьте запись с новым guid и повторите poll. Выполните `php worker.php`, когда срок публикации наступит, и проверьте текст и ссылку в канале.
4. Для расписания вызывайте poll раз в пять минут, worker раз в минуту. Worker берёт одну готовую запись за запуск и выдерживает как минимум 120 секунд между попытками. Параллельные вызовы каждого процесса ограничены локальным файлом блокировки.

| Файл | Назначение |
| --- | --- |
| `poll.php`, `domain.php` | Загрузка RSS, разбор, первый запуск и постановка новых анонсов в очередь. |
| `init.php`, `schema.sql`, `outbox.sql` | Подготовка таблиц истории, очереди и времени отправки. |
| `worker.php`, `outbox.php`, `transport.php` | Выбор готового анонса, обращение к Bot API и сохранение исхода. |
| `fixtures/`, `demo.php` | Три варианта одной ленты и локальная проверка. |

Проверяйте результат запросом `SELECT state, message_id, error_code FROM outbox ORDER BY id;`. При явном ответе Telegram 429 с retry_after запись откладывается. При потере ответа или остановке в состоянии sending сначала сверьте сообщение с каналом.
