# Форма сервисного центра

Требуются тестовый бот, отдельный HTTPS-адрес и 64-битный PHP 8.3+ с cURL, mbstring и PDO SQLite. Один бот использует одну базу. Команды выполняйте из этой папки.

1. Направьте корень HTTPS-сайта на `public/`, включите обработку PHP. Задайте `BOT_TOKEN` тестового бота для CLI и веб-процесса, а для CLI также `APP_URL` с полным HTTPS-адресом формы. Переменные читаются из окружения.
2. Выполните `php install.php`. После «Storage ready» проверьте, что PHP веб-сервера может писать в `var/` и `var/leads.sqlite`. Например, запускайте установку от того же системного пользователя. По HTTP доступны только два файла в public.
3. Выполните `php setup-menu.php`. Команда установит кнопку меню по умолчанию у тестового бота. В его личном чате нажмите «Старт» и «Оставить заявку».
4. Введите «Алёна» и «Хочу подключить уведомления о заказах». После отправки появится номер. Сообщение в чат зависит от ответа Telegram. Для просмотра базы выполните в SQLite `SELECT id, name, question, notification FROM leads ORDER BY id;`.
5. При потере ответа повторите те же поля в этом окне. Сервер вернёт прежний номер. С тем же ключом и другим вопросом он ответит 409. Чтобы отправить другое обращение, нажмите «Новая заявка».

## Карта файлов

| Файл | Назначение |
| --- | --- |
| `public/index.html` | Форма, Telegram WebApp, ключ одной отправки и вывод результата. |
| `public/submit.php` | Проверка HTTP-запроса и полей, вызов сохранения и ответ JSON. |
| `auth.php` | Проверка HMAC, срока и пользователя из initData. |
| `install.php`, `store.php` | Создание схемы, запись в SQLite и поиск при повторе. |
| `setup-menu.php`, `telegram.php` | Настройка меню и отправка одного подтверждения о новой записи. |

Для изменения вопроса можно поменять подпись textarea, сохранив внутреннее имя `question`. Для отдельного поля согласуйте HTML, JSON в fetch, серверную проверку, схему и запросы в store.php, в том числе сравнение при повторе. Для действующей базы примените изменение схемы отдельно. PHP проверяет подпись при каждом POST. Для просмотра HTML вне Telegram откройте страницу обычным браузером — отправка будет недоступна.
