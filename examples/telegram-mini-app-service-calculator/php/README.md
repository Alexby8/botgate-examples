# Калькулятор услуг: пример к статье BotGate

Этот README относится к реализации на PHP. Команды выполняются из
`examples/telegram-mini-app-service-calculator/php`, а не из корня репозитория.
Обзор сценария и список языков — [на уровень выше](../README.md).

Для разработчика, который знает основы HTML, JavaScript и PHP и умеет
размещать PHP-сайт на HTTPS. Composer не нужен.

## Начните с формы из статьи

Минимальный калькулятор — три файла: `pricing.php`, `public/calculator.html`
и `public/calculate.php`. Нужен PHP 8.3+; токен и база для этого шага не нужны.
Из корня примера запустите локальный сервер:

```bash
php -S 127.0.0.1:8080 -t public
```

Откройте http://127.0.0.1:8080/calculator.html. Для 100 ч/б A4 с самовывозом
ожидается 1350,00 ₽, со срочностью и курьером — 2037,50 ₽. Endpoint calculate.php
публичный: он только считает по общим тарифам, не читает и не сохраняет данные
пользователя. Сначала собирается FormData, затем поля блокируются на время запроса.

Для запуска в Telegram разместите эти файлы на HTTPS-хостинге с корнем сайта
`public`. В BotFather вызовите `/setmenubutton`, выберите тестового бота, укажите
HTTPS-адрес `calculator.html` и текст «Рассчитать». Откройте кнопку в чате бота.
Встроенный сервер PHP предназначен только для локальной проверки.

## Дополнительно: сохранение предложения и заявка менеджеру

Это расширенная версия: `public/app.html`, API, SQLite и отправитель уведомлений.
Её сервер использует ту же `pricing.php`. Для этой части нужны PHP 8.3+ в 64-битной
среде, расширения pdo_sqlite, mbstring, curl и настройки ниже. Основной калькулятор
можно использовать отдельно, не подключая эти функции.

1. Создайте отдельного бота в BotFather. Webhook калькулятору не нужен.
2. Скопируйте `config.example.php` в `config.local.php`. На Linux/macOS:
   `cp config.example.php config.local.php`; на PowerShell: `Copy-Item config.example.php config.local.php`.
3. Вставьте токен только в `config.local.php`. Откройте чат нового бота
   со своего аккаунта менеджера, отправьте `/start`, выполните `php connect.php ids`.
   Запишите свой числовой ID строкой в MANAGER_CHAT_ID.
   Если показано несколько ID, используйте отдельного тестового бота,
   которому пока написали только вы. Не выбирайте незнакомый ID наугад.
4. Разместите приложение на отдельном HTTPS-домене. Document root должен
   указывать на папку `public`, например `/srv/calculator/public`.
   Файлы конфигурации, SQLite и CLI не должны быть доступны по HTTP.
   PHP-процессу нужен доступ на запись в `var` и чтение `config.local.php`.
5. Запишите полный HTTPS-адрес `app.html` в MINI_APP_URL. Выполните:

```bash
php init.php
php connect.php menu
```

`init.php` используется один раз для новой базы; меню должно вывести `sent`.
PHP CLI и веб-сервер читают один config.local.php. Если одноимённая переменная
задана в окружении процесса, она имеет приоритет. APP_DB по умолчанию находится
в `var/app.sqlite`; папка var уже включена в пример.

6. Заново откройте личный чат бота и кнопку «Рассчитать». Выберите 100 ч/б A4,
   срочность и курьера. Ожидайте 2037,50 ₽. Сохраните расчёт, затем передайте
   заявку. Выполните `php worker.php` — менеджер получит сообщение.

Запросы app.html к api.php в обычной браузерной вкладке без запуска из Telegram
получат 401. Не выключайте проверку подписи для обхода этой ошибки. Публичный
calculate.php по-прежнему доступен без авторизации, но не умеет сохранять заявки.

## Постоянная отправка

Пример cron для Linux (адаптируйте только путь к своему учебному приложению):

```cron
* * * * * cd /srv/calculator && php worker.php
```

Планировщик выполняется под пользователем с доступом к той же базе. Задержка
уведомления может достигать минуты. Веб-заявка сохраняется сразу.
`unknown` и оставшийся после аварии `sending` не повторяются автоматически:
проверьте чат и конкретную запись outbox, прежде чем повторять отправку.

## Где менять пример

- `pricing.php`: options и price — проверка полей и формула для обеих версий.
- `public/calculator.html`, `public/calculate.php`: минимальная форма из статьи.
- `domain.php`: saveQuote, submitQuote — сохранение предложения и заявки.
- `public/app.html`: форма и предварительный расчёт; код отформатирован для чтения.
- `public/api.php`, `auth.php`: запросы формы и проверка пользователя.
- `common.php`, `values.php`: конфигурация и SQLite.
- `outbox.php`, `transport.php`, `worker.php`: доставка уведомлений.

Изменяя тариф, обновите PHP-функцию price в pricing.php. Минимальная форма
использует только ответ сервера. В расширенной версии также обновите версию
тарифа в saveQuote и preview в app.html: там есть мгновенная оценка на JavaScript.
Серверная цена остаётся окончательной для сохраняемого предложения.
В примере нет оплаты и полноценной CRM. Менеджеру передаётся предварительная заявка.

Для отдельной проверки PHP-логики запустите `php demo.php`: ожидаются 1350,00 ₽,
2037,50 ₽ и `DEMO OK`. Скрипт использует SQLite в памяти и не отправляет сообщения.
