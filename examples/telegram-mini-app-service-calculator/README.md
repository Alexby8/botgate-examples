# Калькулятор стоимости услуг в Telegram Mini App

[Статья с пошаговым разбором](https://bot-gate.ru/guides/telegram-mini-app-service-calculator).

Клиент выбирает параметры и получает предварительную цену, рассчитанную сервером.
Дополнительная часть сохраняет предложение и передаёт заявку менеджеру.
Учебный пример использует печать документов; тарифы можно заменить своими.

## Реализации

- **[PHP](php/README.md)** — серверная формула и API, интерфейс на HTML/JavaScript.

В PHP-варианте есть минимальный калькулятор из трёх файлов и расширение с
сохранением, историей и уведомлениями. Начните с минимального варианта.
Папки других языков можно добавлять рядом с `php`.
