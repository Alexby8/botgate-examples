# База знаний и оператор

Для демонстрации поиска нужен 64-битный PHP 8.3+ с mbstring. Выполните:

```bash
php demo.php
```

Ожидаются ответы про экспорт CSV и приглашение сотрудника со ссылками. Вопрос о возврате денег даёт решение передать его оператору. Демонстрация использует только `fixtures/faq.php`.

Для тестового бота дополнительно нужны cURL, PDO SQLite и HTTPS. Задайте `APP_DB` с путём к закрытой базе, `BOT_TOKEN`, `WEBHOOK_SECRET` и полный `WEBHOOK_URL` до `/webhook.php`. Токен нужен CLI. Путь базы и секрет нужны также PHP веб-сервера. Корень сайта укажите на `public/`.

```bash
php init.php
php setup-webhook.php
php worker.php
```

Откройте личный чат, отправьте /start и тестовые вопросы. Запускайте worker после каждого нового входящего события. `public/webhook.php` сохраняет проверенный Update, `worker.php` вызывает `bot.php`. Поиск находится в `knowledge.php`, ответ в `answer.php`, обращение и переключение режима — в `bot.php`. После вопроса вне справки посмотрите `SELECT id,state,reason FROM tickets;` и вызовите из доверенного CLI `php operator.php 1 "Уточните номер заказа."`.

По умолчанию приложение цитирует справку. Для отдельного теста генерации задайте и `AI_MODEL` с моделью, которая поддерживает структурированный вывод Responses API, и `OPENAI_API_KEY`. Этот режим передаёт текст вопроса и найденные выдержки внешнему API. Выбирайте для такого теста учебные данные.
