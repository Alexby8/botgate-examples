# Заявка на консультацию в чате

Требуются 64-битный PHP 8.2+, mbstring, PDO SQLite и cURL. Команды выполняйте из этой папки. Для проверки диалога достаточно CLI.

```bash
php demo.php
```

Демонстрация использует SQLite в памяти и локальный обработчик отправки. В конце будет одна заявка Анны с исправленным описанием. Повтор события подтверждения и отменённая анкета Веры строк не добавляют.

## Подключение тестового бота

1. Направьте корень отдельного HTTPS-сайта с обработкой PHP на `public/`. Создайте хранилище командой `php install.php`. Обеспечьте процессам PHP и worker доступ на запись к закрытой папке `var/` и её файлам. Удобно запускать CLI от того же системного пользователя.
2. Задайте `WEBHOOK_URL` (полный HTTPS-адрес с `/webhook.php`) и `BOT_TOKEN` тестового бота для CLI. Создайте случайный секрет, например через `php -r 'echo bin2hex(random_bytes(32)), PHP_EOL;'`. Задайте результат в `WEBHOOK_SECRET` для CLI и PHP веб-сервера. Переменные передаются окружением процессов.
3. Запустите `php setup-webhook.php`. Скрипт вызывает setWebhook и заменяет адрес получения обновлений этого бота.
4. В отдельном процессе запустите `php worker.php` с тем же BOT_TOKEN. Оставьте один worker на эту базу и один бот на установку. Worker читает ответы в порядке записи, между проверками пустой очереди ждёт секунду.
5. В личном чате отправьте `/form`, имя, описание от 10 до 1000 символов и `/confirm`. Ожидайте «Заявка сохранена. Спасибо!». Проверьте `SELECT data_json FROM applications;` в `var/form.sqlite`.

## Как связаны файлы

| Файл | Что делает |
| --- | --- |
| `public/webhook.php` | Проверяет секрет Telegram и передаёт личное сообщение на обработку. |
| `form.php` | Выбирает следующий вопрос по шагу, тексту и сроку черновика. |
| `store-form.php`, `schema.sql`, `database.php` | Фиксируют событие, шаг, заявку и исходящий ответ одной транзакцией. |
| `outbox.php`, `worker.php`, `telegram.php` | Забирают ответ, вызывают sendMessage и сохраняют исход. |

Команда `/back` с подтверждения возвращает к описанию, ещё один шаг назад — к имени. `/cancel` очищает черновик. Через 30 минут от старта следующий ответ предложит начать заново. При подтверждённом ответе Telegram 429 с retry_after worker откладывает сообщение, следующие подсказки ждут за ним. Всего допускается три попытки. После потери ответа статус `unknown`, после остановки посреди запроса может остаться `sending`. Перед повторной отправкой разберите исход вручную. Для проверки посмотрите `SELECT update_id, status, attempts, message_id FROM form_outbox ORDER BY rowid;`.
